## DML
- These operations are known as Data Manipulation Language (DML) or CRUD commands
- CRUD stands for Created, Read, Update, Delete

## SQL Injection
- Refers to malicious pratice of inputting the sql statment to compromise security of application.
- Attackers attempt to input data to a site which will interfere with or expose data from db.
- used for 
- 1. Exposed sensitive data
- 2. Bypass authentication
- 3. Modify or delete data
- 4. Execute admin operations
